# V0.1 手工验收

## 前置条件

- 已从 `dist-chrome` 加载“位置记忆 0.1.1”。
- 已登录 ChatGPT。
- 准备两个不同对话 A 和 B，最好至少一个对话超过 30 轮。

## 验收步骤

1. 不打开扩展弹窗。打开对话 A，向上滚动到明显的中间位置，停止至少 3 秒。
2. 直接刷新页面，确认回到同一消息附近，并显示自动恢复提示。
3. 此时再点击扩展图标，确认显示“正在自动记忆当前对话”。
4. 切换到对话 B，滚动到另一个位置，等待 3 秒，全程不点击扩展按钮。
5. 在 A、B 之间来回切换，确认两者自动恢复且互不覆盖。
6. 关闭 A 的标签页，再从 ChatGPT 历史中重新打开 A，确认自动恢复。
7. 完全退出并重新启动 Chrome，再打开 A，确认自动恢复。
8. 恢复进行时立即滚动，确认扩展停止抢夺滚动位置。
9. 关闭“自动记忆与恢复”，刷新页面，确认不自动恢复。
10. 清除当前对话记录，刷新并确认该对话不再恢复；其他对话记录仍保留。

## 通过标准

- A/B 数据隔离；
- 刷新、重开标签和浏览器重启后能够恢复；
- 用户主动滚动优先；
- 没有保存消息正文；
- 关闭功能和清除记录立即生效。

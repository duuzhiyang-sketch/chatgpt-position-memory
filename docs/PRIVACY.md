# 隐私说明

## 保存的数据

- ChatGPT 对话 ID 派生出的本地键；
- 可用时保存 ChatGPT 页面提供的消息 ID 或 turn test ID；
- 消息序号、用户/助手角色；
- 视口参考点、像素偏移、滚动比例；
- 最后保存时间。

## 不保存的数据

- 消息正文或选中文本；
- 对话标题；
- 输入框草稿；
- Cookie、登录凭证或令牌；
- 完整 URL 查询参数和 hash；
- 浏览历史或其他网站数据。

## 数据去向

数据仅写入本扩展的 `chrome.storage.local`。源码中没有 `fetch`、`XMLHttpRequest` 或 `WebSocket` 网络客户端。卸载扩展会由 Chrome 删除该扩展的本地存储；也可以在扩展弹窗中单独清除当前对话或全部记录。

`scripting` 权限只用于在安装、更新或浏览器启动后，把本扩展自己的内容脚本接入已经打开的 ChatGPT 标签页；不会向其他网站注入。

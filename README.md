# 位置记忆

“位置记忆”是一个独立实现的 Chrome MV3 扩展，只做一件事：为每个 ChatGPT 对话保存最后阅读位置，并在刷新或重新打开该对话时恢复。

## 项目边界

- 独立代码库、独立 Git 历史、独立名称与图标。
- 未复制 AI-MarkDone 的源码、界面、资源或测试。
- 零运行时依赖，不包含服务器、账号系统、云同步或分析追踪。
- 当前 `package.json` 标记为 `UNLICENSED`，尚未附加开源许可证。

## 功能

- 支持 `chatgpt.com` 和旧域名 `chat.openai.com`。
- 从 `/c/<conversation-id>` 路由识别对话，忽略查询参数和 URL hash。
- 无需打开扩展弹窗：滚动停止后自动保存，并每 2.5 秒核对一次当前可见位置。
- 优先按消息身份恢复；目标暂未挂载时，以滚动比例辅助长对话加载。
- 用户在恢复期间主动滚动会立即取消恢复。
- 每个对话独立保存；多标签页写入采用最后写入优先。
- 工具栏弹窗提供总开关、恢复提示开关、清除当前记录和清除全部记录。
- 安装、更新或浏览器启动时自动接入已经打开的 ChatGPT 标签页。

## 本地安装

需要 Chrome 和 Node.js 20 或更高版本。

1. 在 GitHub 仓库点击 **Code → Download ZIP** 并解压，或克隆仓库。
2. 在解压后的项目目录执行以下命令，生成 `dist-chrome`。项目没有第三方依赖，无需安装依赖或填写 API Key。

   ```sh
   npm run build
   ```

3. 在 Chrome 地址栏打开 `chrome://extensions`。
4. 开启“开发者模式”。
5. 点击“加载已解压的扩展程序”，选择生成的 `dist-chrome` 目录。
6. 打开 ChatGPT 对话并正常阅读，扩展会自动记忆位置。

如果已经加载旧构建，重新执行构建后，在扩展卡片上点击一次“重新加载”。此后日常使用不需要点击扩展按钮。

## 开发与验证

```sh
npm run verify
```

该命令依次执行语法检查、自动化测试、构建和构建包审计。项目没有第三方 npm 依赖。

## 隐私

扩展只在 `chrome.storage.local` 保存对话 ID、消息 ID/轮次位置、视口偏移、滚动比例和时间戳。不会保存消息正文、对话标题、输入草稿、Cookie、凭证或浏览记录，也不会主动发起网络请求。

位置记录保存在浏览器内，不在源码目录中。分享源码无需导出浏览器配置、Cookie 或本地存储。提交问题反馈时，请勿附带真实对话链接、聊天截图或账号凭证。

完整说明见 [docs/PRIVACY.md](docs/PRIVACY.md)。

## 已知边界

ChatGPT DOM 不是公开稳定接口。若官网更改对话路由、消息属性或滚动容器结构，需要更新内容脚本。目标消息尚未加载或已被虚拟化时，V0.1 会先恢复到接近位置，并在限定时间内继续寻找精确锚点。
